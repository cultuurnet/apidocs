# 2026 Deployments 

## November 10

✨ New Features

* BOA template: a new pre-configured template to quickly publish agendas for afterschool care and leisure activities (Buitenschoolse Opvang en Activiteiten).
* Search box:
  * New way date picker (with the possibility to quickly select holiday periods)
  * Age filter: allows visitors to filter events and activities by ages
* Detail page: new settings
  * Departure places: allows to display the departure place for activities
  * FAQ: allows to display the FAQ of an acitivity
* Badges:
  ** Overnight Stay: visual badge highlighting the overnight stay of a camp
  ** "Alleen voor kinderen": visual badge identifying activities exclusively intended for children.

🛠 Improvements

* Updated Vlieg Label
* Date, time of the activity and time of childcare are now displayed separately in the search results.
* Birth Date display: target age requirements can now be shown as birth dates or birth years instead of ages.
* Extended calendar information: detail pages now support the `xl` calendar summary, displaying exceptions and closing days.
* Event type icons: event type badges now feature matching icons for quicker visual recognition.
