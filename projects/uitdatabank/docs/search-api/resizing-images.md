# Resizing images

## Why resize images?

Images in UiTdatabank can have a size up to 20MB. Therefore, we highly recommend to resize these images for your own web page. When using the right parameters, resizing images will positively impact page speed without any loss of visible quality.

## How to resize

To resize an image, add one or more parameters to the image URL found in the `contentUrl` property of the image (e.g. `https://images.uitdatabank.be/{imageId}.jpeg`).

Use `maxwidth` and/or `maxheight` to scale the image down so it fits within the given bounds. The aspect ratio of the image is preserved, so no whitespace is added and nothing is cut off.

```
GET /image/{imageId}?maxwidth=800&maxheight=600
```

Use `width` and/or `height` instead if the image must have exactly the given dimensions. If the aspect ratio of the original image is different, whitespace is added to fill the remaining space. You can set the color of this whitespace with `bgcolor`.

```
GET https://images.uitdatabank.be/{imageId}.{fileExtension}?width=800&height=600&bgcolor=ffffff
```

## How to crop

If you need an image with exact dimensions but don't want whitespace, you can crop it instead. Combine `width` and `height` with the `crop` parameter to remove the outer areas of the image that don't fit.

```
GET https://images.uitdatabank.be/{imageId}.{fileExtension}?width=800&height=600&crop=auto
```

With `crop=auto` the crop focuses on the busiest part of the image (the same as `crop=entropy`). See [crop](#crop) for all possible values.

## AI label

Images that are marked as AI generated (see [AI generated images](../entry-api/shared/images.md#ai-generated-images)) get a watermark label in the top left corner, so end users can see that the image was generated by AI.

**We recommend keeping the top left 30px of AI generated images free of other elements (like text, icons or buttons) in your layout, so the AI label stays visible.**

## Parameters

### bgcolor

With the `bgcolor` parameter you can set the background / whitespace color of an image.

**Possible values**

Any hex code (3 or 6 characters), without `#`

**Example**

```
GET https://images.uitdatabank.be/{imageId}.{fileExtension}?bgcolor=fff
```

### crop

With the `crop` parameter unwanted outer areas from the image will be removed. Cropping only works in combination with both `width` and `height`; without them, `crop` has no effect.

**Possible values**

* `auto`: crops the image to the size specified by `width` and `height`, focusing on the busiest part of the image.
* `edges`: crops the image to the size specified by `width` and `height`, focusing on an area of interest found by edge detection (looking for objects within the image).

**Example**

```
GET https://images.uitdatabank.be/{imageId}.{fileExtension}?width=800&height=600&crop=edges
```

### format

With the `format` parameter you can convert the image to a different output format.

**Possible values**

See [imgix documentation](https://docs.imgix.com/apis/rendering/format/fm)

**Example**

```
GET https://images.uitdatabank.be/{imageId}.{fileExtension}?format=png
```

### flip

**Possible values**

* `h`: flips the image (horizontally) after resizing
* `v`: flips the image (vertically) after resizing
* `both`: flips the image after resizing

**Example**

```
GET https://images.uitdatabank.be/{imageId}.{fileExtension}?flip=h
```

### height

With the `height` parameter you can force the height to certain dimensions. Whitespace will be added if the aspect ratio is different.

**Possible values**

Any positive integer.

**Example**

```
GET https://images.uitdatabank.be/{imageId}.{fileExtension}?height=400
```

### maxheight

With the `maxheight` parameter you can fit the image within the specified height bounds.

**Possible values**

Any positive integer.

**Example**

```
GET https://images.uitdatabank.be/{imageId}.{fileExtension}?maxheight=
```

### maxwidth

With the `maxwidth` parameter you can fit  the image within the specified width bounds.

**Possible values**

Any positive integer.

**Example**

```
GET https://images.uitdatabank.be/{imageId}.{fileExtension}?maxwidth=
```

### paddingWidth

With the `paddingWidth` parameter you can add padding by the number of pixels specified

**Possible values**

Any positive integer.

**Example**

```
GET https://images.uitdatabank.be/{imageId}.{fileExtension}?paddingWidth=
```

### rotate

With the `rotate` parameter you can change the orientation of the image, by rotating around its center. Rotation is always done counter-clockwise with `0` (default value) at the top of the image.

**Possible values**

Positive integers in the range of `0` - `359`

**Example**

```
GET https://images.uitdatabank.be/{imageId}.{fileExtension}?rotate=180
```

### width

With the `width` parameter you can force the width to certain dimensions. Whitespace will be added if the aspect ratio is different.

**Possible values**

Any positive integer.

**Example**

```
GET https://images.uitdatabank.be/{imageId}.{fileExtension}?width=
```

## Mapping table

When adding resize parameters to images in UiTdatabank, you will first be redirected to a parameter mapping vhost, which will resemble the old image resizing parameters to parameters that can be processed by [imgix](https://docs.imgix.com/apis/url).
This vhost contains a mapping table that converts the old parameters to imgix parameters and returns a redirect to imgix.

Mapping is done using the following table:

| Original parameters              | Imgix parameters                     |
| -------------------------------- | ------------------------------------ |
| bgcolor=123456                   | bg=123456                            |
| crop=auto                        | fit=crop\&crop=entropy               |
| crop=edges                       | fit=crop\&crop=edges                 |
| format=png                       | fm=png                               |
| flip=h                           | flip=h                               |
| flip=v                           | flip=v                               |
| flip=both                        | flip=hv                              |
| height=200                       | h=200\&fit=fill\&bg=FFFFFF           |
| maxheight=200                    | h=200                                |
| maxwidth=300                     | w=300                                |
| maxwidth=500\&maxheight=400      | w=500\&h=400                         |
| paddingWidth=5                   | pad=5\&bg=FFFFFF                     |
| rotate=30                        | rot=30                               |
| width=300                        | w=300\&fit=fill\&bg=FFFFFF           |
| width=500\&height=400            | w=500\&h=400\&fit=fill\&bg=FFFFFF    |
| width=500\&height=400\&crop=auto | w=500\&h=400\&fit=crop\&crop=entropy |
